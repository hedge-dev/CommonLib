enum class hedgedev::csl::hook::user_register : uint64_t
strong

Registers used for __usercall/__userpurge calling conventions.

These registers have been ordered in an specific way that line up with register IDs used for encoding instructions.

Parameters

in_addressThe address of the __cdecl function to trampoline to.
in_to_originalDetermines whether this trampoline is going back to the original function.
