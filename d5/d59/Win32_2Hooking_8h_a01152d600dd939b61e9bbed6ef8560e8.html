◆ STATIC_ASM_HOOK [1/2]

#define STATIC_ASM_HOOK ( NAME,
ADDRESS )

Creates an assembly hook, and installs it upon initialisation.

Parameters
NAMEThe name of the hook.
ADDRESSThe address to hook.
Note
For x64: The body must be defined in an *.asm file using MASM. This macro creates a scope for members of the hook to be declared in. If no members are needed, close the scope immediately using empty braces.

Examples

x86

Mod.cpp

ASM_HOOK(MyAsmHook, 0xDEADBEEF)
{
static uint32_t g_myHookMember = 0x900DF00D;
__asm
{
mov eax, [g_myHookMember]
}
ASM_HOOK_BRANCH(MyAsmHook)
}
