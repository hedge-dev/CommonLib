◆ THISCALL_PARAMS

#define THISCALL_PARAMS ( CLASS_NAME)

Expands to the necessary function parameters required by __thiscall calling convention.

Parameters
CLASS_NAMEThe name of the class this function is from.
Note
For x86: This macro creates a discard parameter to fill in for EDX, allowing the rest of the arguments to be pushed onto the stack.
For x64: This macro uses standard __fastcall conventions.

Examples

FUNCTION_PTR(int, THISCALL, fpMyClassFunction, 0xDEADBEEF, THISCALL_PARAMS(MyClassName), int in_secondParam);
