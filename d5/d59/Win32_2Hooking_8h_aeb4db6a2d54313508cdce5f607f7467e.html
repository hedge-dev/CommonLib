Defines the body of a hook for a function in memory, and installs it upon initialisation.

Parameters

CALLING_CONVENTIONThe calling convention of the function (e.g. __cdecl, __stdcall, __fastcall, etc). For custom calling conventions on x86, such as __usercall or __userpurge, see HookingUserCall.h.
FUNCTION_NAMEThe name of the function.
ADDRESSThe address of the function.
